GradingBuddy

A Chrome side panel that keeps the AC/PL standards, subgrade thresholds and cert lookup next to the grading platform while you work.

Installing it

One time, about two minutes. You only repeat this when a new version ships.

If something goes wrong

The panel is blank. Reload the grading platform tab. The extension attaches on page load.

Chrome says the extension is unsupported. You are on a managed profile. Ask IT to allow-list the extension ID rather than turning off developer mode.

It disappears after restarting Chrome. Unpacked extensions unload if the folder moves. Keep the unzipped folder somewhere permanent, not in Downloads.
